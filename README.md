# Frame Monitor 0.1.0

Первая версия Android-монитора с просмотром медиа по USB. Проект написан на Java с системными Android API. Интернет приложению не нужен.

## Сборка на Windows

1. Распакуй архив и открой папку FrameMonitor в Android Studio.
2. Установи Android SDK Platform 35 и выбери JDK 17 или совместимый встроенный JDK для Gradle. Проект использует Android Gradle Plugin 8.9.2 и Gradle 8.11.1.
3. Если Android Studio попросит указать Gradle, выбери локальную установку Gradle 8.11.1. С установленным Gradle можно собрать проект из его папки командой `gradle assembleDebug`.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Минимальная версия системы для установки — Android 7.0.

## Как проверить на телефоне

| Подключение | Действия | Что проверить |
|---|---|---|
| PTP/MTP | Включи на камере PTP/MTP или режим передачи фотографий. Подключи кабель данных через OTG, нажми «PTP / MTP» и выдай разрешение. | Открываются карты и папки. JPG отображается. MP4 воспроизводится при поддержке кодека. Оригинал сохраняется в выбранное место. |
| USB-накопитель или кардридер | Подключи устройство и нажми «USB-файлы». Выбери фото или видео в системном окне Android. | Android видит накопитель. Выбранный файл открывается. |
| UVC | Включи USB Streaming на камере либо подключи HDMI через UVC-карту захвата. Нажми «Монитор», затем «Вход». | Внешний вход появляется в списке, отображается видео, работают сетка и зум 2×. |

Проверь также отказ в USB-разрешении, отключение кабеля во время просмотра карт, подключение заново и переключение ориентации телефона.

## Границы версии

- PTP/MTP используется в режиме чтения. Предпросмотр загружает выбранный файл во временное хранилище телефона. Для крупных роликов нужно свободное место. Для сохранения оригинала приложению также нужно место под временный файл.
- Список показывает имена файлов. Миниатюр и потокового предпросмотра PTP/MTP пока нет. Просмотр зависит от поддержки формата и кодека в Android.
- Для UVC требуется, чтобы производитель телефона предоставлял внешнюю камеру через Camera2. Видео и файловый режим выбираются отдельно. Звук с UVC не захватывается.
- Поддержка iOS, команды REC/ISO, Wi-Fi и инструменты экспозиции из спецификации ещё не реализованы.
- APK и физические устройства в среде разработки недоступны. Совместимость проверяется на конкретной связке камеры и телефона по таблице выше.
